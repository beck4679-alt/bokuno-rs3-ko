# Localization reference / 현지화 참고 자료

[메인으로](../README.md)

다른 언어 현지화에 참고할 수 있도록 공유한 구현 자료입니다. ROM 분석·개발·번역 및 검토 과정에 AI를 사용했으며, 아래 설명과 자료 정리에도 AI의 도움을 받았습니다.

| 자료 | 내용 |
|---|---|
| [워커·빌더 핵심 7개 파일 (2026-09-21)](localization-reference/2026-09-21/README.md) | 대사·분기 추출, 글리프와 폰트 처리, 번역문 확장 및 ROM 삽입 |
| [명령어·실행 중 텍스트 추가 모듈 (2026-09-23)](localization-reference/2026-09-23/README.md) | 명령어 길이, 이름·숫자 처리, 조건 분기와 ROM 식별 |

각 문서에 ZIP 다운로드와 파일별 설명이 있습니다. 원래 공유한 파일과 링크는 유지했습니다. 이 자료는 구현을 살펴보기 위한 소스 스냅샷이며, 전체 번역 데이터나 독립 실행 가능한 빌드 도구 모음은 아닙니다.

English documentation and source ZIPs are available through the links above. These are reference snapshots, not a complete standalone build kit. Development and preparation of these materials used AI assistance.
