# v0.114 — 괴문자(연결 안 된 원문) 전수 수리

v0.113까지의 변경을 포함한 누적 한국어 패치입니다.

> **정정(2026-10-06)**: 아래 「한국어 글 안에서 이벤트가 끝나 대사가 끊기는 자리 0곳」은 이벤트 자체의 끝 표지만 센 것입니다. 다른 대본을 불러 실행하는 부분의 끝 표지 자리에 한국어 글이 놓여 대사가 도중에 끝나는 곳이 3곳(게코족 촌장 대화·데스티니 스톤 설명·루퍼스 임무 대사) 있었고, 게코족 해방 이벤트는 이 때문에 진행이 막혔습니다. [v0.117](v0.117.md)에서 고쳤습니다.

## 수정 내용

디스코드 검수 채널에 올라온 캡처 여섯 장 가운데 두 장은 v0.113 에서 이미 고쳐진 화면이었고, 나머지 네 장의 원인을 찾아 같은 원인을 가진 자리까지 롬 전체에서 함께 고쳤습니다.

- **디스코드 제보 괴문자 네 곳**: 번역문이 롬에 연결되지 않아 원문이 괴문자로 찍히던 「ムッ。」「ぐおおーん」「誰ぞ」를 「흠.」「그오오오옹」「누구냐」로 고쳤습니다. 사루인 부하의 「가증스러운 미르자의 유품,」 줄은 번역이 있었는데도 연결 위치가 한 바이트 어긋나 줄 전체가 괴문자였습니다.
- **같은 원인 전수 확인**: 자동 검사 도구가 닿지 않는 장면에서 원문이 그대로 찍히던 자리를 롬 전체에서 찾아 함께 고쳤습니다(새로 채운 줄 27개, 연결 위치 바로잡음 4개).
  - 배틀 시뮬레이터 안내(「배틀 시뮬레이터에 / 도전해 / 보시겠습니까?」), 휴식 확인 선택지 「예」, 경매 선택지 「넘긴다」, 「준비는 됐나?」, 「특별한 정보는 없어.」, 「멀리서 짐승의 / 낮은 으르렁 소리가」
  - 「정말로 그만두시는 겁니까?」 줄 전체, 「네가 지키고 있다는」 앞 글자, 용의 눈 이야기 앞뒤 글자(「그건 용의 눈이잖아. … 부적이었던 거야.」)
  - 대사 끝에 남던 일본어 마침표 「。」 두 곳, 겹쳐 찍히던 말줄임표 한 곳, 동료 선택지 「삼지 않는다」, 디버그 메뉴

## 확인한 범위

- 전체 필수 빌드 검사를 통과했습니다. 본문 24,938행·사전 767칸 되읽기 일치, 이벤트 흐름 919개(실제 비교 802개)에서 원문 대비 차이·잘못된 복귀 0건, 한국어 글 안에서 이벤트가 끝나 대사가 끊기는 자리 0곳.
- 실제 코어 화면: 고친 자리 20곳 가운데 19곳을 검수 후보에서 실제 에뮬레이터 코어로 열어 기대한 한국어가 찍히는 것을 확인했습니다(대사를 여는 명령부터 직접 실행한 확인이며, 실제 게임 진행으로 그 장면까지 간 화면은 아닙니다). 이 가운데 세 곳은 수정 전 판(v0.113)에서 괴문자로 찍히는 것을 먼저 확인했습니다.
- 전체 대사 재추출: 새 번역이 들어가며 기존 한국어 글 8,661곳의 저장 위치가 옮겨져, 전체 대사(3,865개 이벤트 × 주인공 8명)를 다시 추출해 이전 판과 대조했습니다 — 바뀐 대사 0, 이벤트 끝 주소가 한국어 글 안에 떨어지는 자리 0.
- 원본 보쿠노 롬에 이 xdelta 를 적용한 결과가 검수 후보와 일치하는지 SHA-256 으로 확인했습니다. 글자 배정은 v0.113 과 같아 기존 세이브를 그대로 쓸 수 있습니다.

## 남은 검수

일부 조연 대사의 「あんた」와 대명사 높임, 사라 선택지 한 곳의 말투, 7×1 영지 경영 창, 새 글꼴의 상태창·장비 메뉴 전체 표시, 트레이드 화면의 자연 진입 후 전체 배치, 자동 검사 도구가 닿지 않는 장면의 줄 배치는 확인하지 못했습니다. **전체 무결함 판정은 아닙니다.**
