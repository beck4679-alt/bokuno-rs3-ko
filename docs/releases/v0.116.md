# v0.116 — 동료 가입 뒤 그림·LP 깨짐 수리(2회차 엘렌 등)

v0.115까지의 변경을 포함한 누적 한국어 패치입니다.

## 수정 내용

디스코드로 보내 주신 세이브로 「엘렌을 동료로 삼은 뒤 그림·LP 가 깨진다(2회차)」 제보의 원인을 찾았습니다. 원본 보쿠노가 아니라 한국어 패치의 결함이었습니다.

- **동료 가입 뒤 그림·LP 깨짐(2회차 엘렌 등)**: 한국어 패치가 대사를 표시할 때 쓰는 임시 메모리 자리가 보쿠노가 추가한 확장 대기 동료 목록의 한 칸(28번째)과 겹쳐 있었습니다. 대사가 나올 때마다 그 칸에 가짜 동료 기록(율리안·엘렌)이 생겨, 엘렌(또는 율리안)을 동료로 삼을 때 게임이 이 가짜 기록을 집어 들면 그림이 다른 인물로 나오거나 LP·HP 가 엉뚱한 값이 되었고, 2회차로 넘어갈 때도 깨진 기록이 넘어갔습니다. 대기 동료가 54명 이상으로 많아지면 그 칸에 들어간 실제 동료 기록이 대사 표시 때 덮여 사라졌고, 대기 동료 수도 하나 많게 세어졌습니다. 첫 공개판(v0.78)부터 있던 결함입니다. 임시 메모리를 게임이 쓰지 않는 자리(스택 여유 공간)로 옮겼습니다.
- **이전 판 세이브 자동 정리**: 세이브를 불러올 때 이전 판이 남긴 가짜 대기 동료 기록을 지우고 대기 동료 수를 다시 셉니다(그 칸 뒤에 다른 동료가 있으면 원래 게임 규칙대로 당겨 채웁니다). 진짜 율리안·엘렌 기록은 그대로 둡니다.
- **정정**: v0.115 에서 「재현하지 못했다(원본·한국어판 모두 정상)」고 적은 엘렌 제보는 한국어 패치 결함이었습니다. 그때의 시험은 엘렌이 대사보다 먼저 가입하는 조건이라 증상이 가려졌습니다. 보내 주신 세이브로 원인을 찾았습니다.

## 확인한 범위

- 전체 필수 빌드 검사를 통과했습니다. 본문 24,943행·사전 767칸 되읽기 일치, 이벤트 흐름 919개(실제 비교 802개)에서 원문 대비 차이·잘못된 복귀 0건, 한국어 글 안에서 이벤트가 끝나 대사가 끊기는 자리 0곳, 군단전이 읽는 이름 표에서 잘못 읽히는 글자 0개. 이번에 새로 넣은 메모리 검사(새 게임 오프닝·동료 가입과 메뉴·군단전·전투 네 상황)에서 한국어 패치 코드가 게임·보쿠노의 저장 상태 메모리를 쓴 곳 0, 게임 코드가 한국어 패치 전용 임시 메모리를 건드린 곳 0입니다(v0.115 에 같은 검사를 돌리면 겹친 자리를 정확히 잡아냅니다).
- 실제 코어 화면: 보내 주신 세이브로, 대사가 나온 뒤 엘렌을 동료로 삼는 조건을 원본 보쿠노·v0.115·v0.116 에서 실제 에뮬레이터 코어로 같은 조작으로 재현했습니다 — v0.115 는 엘렌 자리에 율리안 그림이 나오고 HP 가 엉뚱한 값이 되며, v0.116 은 원본과 같은 엘렌 기록이 들어옵니다. 불러오기 자동 정리는 2회차 세이브(가짜 기록 제거)와 확장 대기 목록이 가득 찬 1회차 세이브(마지막 동료를 당겨 채움)로 확인했고, 정리 루틴은 실기 CPU 시험 7가지(빈 칸·가짜 엘렌·가짜 율리안·진짜 율리안/엘렌 보존 등)를 통과했습니다.
- 화면 대조: 이번 수정은 임시 메모리 주소와 불러오기 정리 루틴만 바꿉니다(v0.115 대비 바뀐 롬 바이트 285개). 대사 저장 위치와 글자 배정이 하나도 바뀌지 않아 전체 대사 재추출은 하지 않았고, 대신 장면 48개를 v0.115 와 같은 방법으로 열어 화면을 비교했습니다 — 46개는 픽셀까지 같고, 2개는 첫 대사 전 마을 사람이 움직이는 시점만 다릅니다(새 임시 메모리 자리의 처음 값이 옛 자리와 달라서 생기는 차이로, 처음 값을 같게 두면 두 장면도 전부 같습니다).
- 원본 보쿠노 롬에 이 xdelta 를 적용한 결과가 검수 후보와 일치하는지 SHA-256 으로 확인했습니다. 글자 배정은 v0.115 와 같아 기존 세이브를 그대로 쓸 수 있습니다(불러올 때 가짜 대기 동료 기록이 자동으로 지워집니다).

## 남은 검수

이미 세이브에 들어간 깨진 기록은 고치지 못했습니다. 이전 판 클리어 데이터로 시작하는 2회차의 자동 정리, 술집에서 동료를 내보낼 때의 오류 화면, 일부 조연 대사의 「あんた」와 대명사 높임, 사라 선택지 한 곳의 말투, 7×1 영지 경영 창, 새 글꼴의 상태창·장비 메뉴 전체 표시, 트레이드 화면의 자연 진입 후 전체 배치, 자동 검사 도구가 닿지 않는 장면의 줄 배치는 확인하지 못했습니다. 세이브 확인 문구는 아직 고치지 않았습니다. **전체 무결함 판정은 아닙니다.**
