# v0.115 — 디스코드 제보 수리(빛모래 로브·방벽파진)

v0.114까지의 변경을 포함한 누적 한국어 패치입니다.

## 수정 내용

디스코드 검수 채널에 올라온 제보 가운데 「빛모래 로브」와 「방벽파진」 깨짐의 원인을 찾아, 같은 원인을 가진 자리까지 함께 고쳤습니다. 엘렌 그림이 깨진다는 제보는 아직 재현하지 못했습니다([알려진 문제](../KNOWN_ISSUES.md) 참고).

- **술집 의뢰 「빛모래 로브」 깨짐**: 아이템 이름 바로 뒤 「를」 자리가 번역에서 빠져 원문 글자가 「로브」 위에 겹쳐 찍히던 것을 고쳤습니다(「빛모래 로브를 / 갖고 싶어 하는 분이 / 있습니다.」). 조사는 아이템 이름의 받침에 따라 을/를로 바뀝니다.
- **군단전 「방벽파진」 깨짐**: 군단전 화면이 「벽」 글자를 표시 명령으로 잘못 읽어 「방 지휘관 0 파진」처럼 나오던 것을 고쳤습니다. 같은 원인으로 깨지던 지휘관 이름 「뭉그족」과 지휘관 칭호 「철벽」도 함께 고쳐졌습니다.
- **같은 원인 전수**: 이름 뒤에 일본어 쉼표 「、」·느낌표 「！」가 남던 대사 세 곳(파티원 이름 뒤 「,」 두 곳, 경매 아이템 이름 뒤 「!」)과, 영지 경영 상태창의 잔금 「X만 오람」에서 「만」이 다른 글자로 찍히던 것을 고쳤습니다.

## 확인한 범위

- 전체 필수 빌드 검사를 통과했습니다. 본문 24,943행·사전 767칸 되읽기 일치, 이벤트 흐름 919개(실제 비교 802개)에서 원문 대비 차이·잘못된 복귀 0건, 한국어 글 안에서 이벤트가 끝나 대사가 끊기는 자리 0곳, 군단전이 읽는 이름 표에서 잘못 읽히는 글자 0개(이번에 새로 넣은 검사).
- 실제 코어 화면: 고친 자리 가운데 다섯 곳(빛모래 로브, 방벽파진, 파티원 이름 뒤 「,」 두 곳, 경매 「!」)을 수정 전 판(v0.114)과 수정 판에서 실제 에뮬레이터 코어로 같은 방법으로 열어 비교했습니다(대사를 여는 명령부터 직접 실행한 확인이며, 실제 게임 진행으로 그 장면까지 간 화면은 아닙니다). 글자 번호를 바꾼 「벽」「떡」이 든 다른 대사는 수정 전과 화면이 픽셀까지 같습니다. 영지 경영 상태창은 이 방법으로 띄울 수 없는 창이라 대사 추출 결과로만 확인했습니다.
- 전체 대사 재추출: 새 번역이 들어가며 기존 한국어 글 3,106곳의 저장 위치가 옮겨져, 전체 대사(3,865개 이벤트 × 주인공 8명)를 다시 추출해 이전 판과 대조했습니다 — 바뀐 대사는 영지 경영 41개 장면의 「잔금굴 → 잔금만」뿐이고, 이벤트 끝 주소가 한국어 글 안에 떨어지는 자리 0.
- 원본 보쿠노 롬에 이 xdelta 를 적용한 결과가 검수 후보와 일치하는지 SHA-256 으로 확인했습니다. 글자 배정은 네 자(벽·꿨·뭉·떡)의 번호만 v0.114 와 서로 바뀌었고, 기본 주인공 이름과 이름 입력 자판에는 쓰이지 않는 글자라 기존 세이브를 그대로 쓸 수 있습니다.

## 남은 검수

카타리나 루트 엘렌 그림·LP 제보(세이브 필요), 일부 조연 대사의 「あんた」와 대명사 높임, 사라 선택지 한 곳의 말투, 7×1 영지 경영 창, 새 글꼴의 상태창·장비 메뉴 전체 표시, 트레이드 화면의 자연 진입 후 전체 배치, 자동 검사 도구가 닿지 않는 장면의 줄 배치는 확인하지 못했습니다. **전체 무결함 판정은 아닙니다.**
