# v0.112 — 줄 넘김 수리

v0.111까지의 변경을 포함한 누적 한국어 패치입니다.

## 수정 내용

v0.111 을 게시하며 공개한 전체 대사 줄 배치 검사 결과를 고쳤습니다.

- **에롤에게 비는 대사**(여러 장면이 같이 쓰는 문장, 좁은 창·넓은 창 모두 사용): 넓은 창에서 「!」가 혼자 다음 줄로 떨어지던 것을 「아주 조금이라도 괜찮으니.... 힘을 빌려 줘!」로 고쳤습니다.
- **뮤즈의 꿈 속 대사**: 좁은 창에서 「....」이 줄 머리로 넘어가던 것 → 「도움을 못 부를 텐데요....」
- **외딴섬 안개 이야기**(두 장면): 좁은 창에서 「.」이 혼자 남던 것 → 「가까이 안 가는 게 신상에 좋아.」
- **「감쪽같이 / 걸려들고 / 말았다는 거군.」**(남·여 갈래): 끝말 「거군.」이 혼자 한 줄을 차지하던 것
- 창 크기를 확정하지 못한 대사 다섯 곳을 좁은 창에서도 넘치지 않게 다듬었습니다: 「영 마음이 후련하지 않다....」, 「억지로 받아들이지 않으셔도....」, 「네놈 누이 린은 우리가 잡았다.」, 「그놈 있는 곳으로 안내해 주세요!」, 「내가 죽을 때까지 / 알려선 안 되네.」(같은 대사가 나오는 다른 자리와 같은 줄바꿈)

## 확인한 범위

- 전체 필수 빌드 검사를 통과했습니다. 본문 24,880행·사전 767칸 되읽기 일치, 이벤트 흐름 919개(실제 비교 802개)에서 원문 대비 차이·잘못된 복귀 0건.
- 전체 대사(3,865개 이벤트 × 주인공 8명)를 다시 추출해 v0.111 과 대조했습니다. v0.111 과 달라진 대사는 이번에 고친 풍선들(같은 문장을 쓰는 다른 장면 포함)뿐입니다.
- 한국어 글 안에서 이벤트가 끝나 대사가 끊기는 자리: 0곳.
- 전체 대사 줄 배치 검사: 결함 0곳입니다. 검사기가 결함으로 센 1곳(술법 계통 표의 빈 줄)은 원본 롬도 같은 모양임을 실제 코어로 확인한 검사기 오판입니다. 창 크기를 기록으로 확정하지 못한 지크의 누이 대사(2묶음)는 대사 창으로 쓰이는 두 크기(좁은 창·넓은 창) 모두에서 정상입니다.
- 주인공별 말투 갈래 680개를 실제 대사 처리 코드로 걸어 기대 문안과 대조했습니다(불일치 0). 설치된 말투 글과 조사 검사 결과는 v0.111 과 같습니다.
- 실제 코어 화면: 뮤즈의 꿈 속 대사, 외딴섬 안개 이야기, 「감쪽같이 걸려들고 말았다는 거군/거네」, 에롤에게 비는 대사(좁은 창·넓은 창 둘 다)를 검수 후보에서 실제 에뮬레이터 코어로 확인했습니다.
- 원본 보쿠노 롬에 이 xdelta 를 적용한 결과가 검수 후보와 일치하는지 SHA-256 으로 확인했습니다. 글자 배정은 v0.111 과 같습니다.

## 남은 검수

일부 조연 대사의 「あんた」와 대명사 높임, 사라 선택지 한 곳의 말투, 7×1 영지 경영 창, 새 글꼴의 상태창·장비 메뉴 표시는 확인하지 못했습니다. **전체 무결함 판정은 아닙니다.**
