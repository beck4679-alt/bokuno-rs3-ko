# v0.110 — 구시가 대사·줄바꿈 수정

v0.109까지의 변경을 포함한 누적 한국어 패치입니다.

## 수정 내용

- **구시가 피난민 대사:** 「많이 도망쳐 와」 뒤 개행과 문장 끝 빈 줄을 정리했습니다. 루트비히에게 쫓긴 사람들을 설명하는 대사가 넓은 창·좁은 창 모두 세 줄로 표시됩니다.
- **대사 줄바꿈 63행:** 스탠리 흡혈귀 이야기, 왕가의 반지 설명, 루트비히 용병 모집 등에서 불필요한 개행을 정리했습니다. 이번 묶음에서는 공백·개행 외 본문을 바꾸지 않았습니다.
- **공유 대사 영향:** 같은 문구를 쓰는 다른 말풍선과 버튼 대기 구간을 각각 대조했습니다. 한 대화의 개선으로 다른 대화의 악화를 상쇄하지 않도록 검사했습니다.

## 확인한 범위

- 수정 행을 사용하는 180개 문맥·1,415회 출력을 최종 롬에서 다시 추출했습니다. 누락·새 미대응·문안 불일치 및 스크롤·어절 잘림·빈 줄 등의 추가 악화는 확인한 범위에서 0건입니다.
- 넓은 창·좁은 창 및 관측된 창 조건을 비교하고, 사용자 이름 길이 1~8글자의 모델 검사 272가지를 확인했습니다.
- 실제 코어에서 주요 5개 본문을 두 창으로 총 10회 재현했습니다. 원래 창 명령과 대기를 사용하는 통제 재현이며 모든 자연 플레이 경로를 확인한 것은 아닙니다.
- 전체 필수 빌드 검사를 통과했습니다. 이벤트 흐름 802개 비교에서 차이·잘못된 복귀 0건, 공유 조회 연결 22,425개와 수정 대상 밖 본문 보존을 확인했습니다. 양쪽 모두 발동하지 않은 117개 이벤트는 실제 비교에서 제외했습니다.
- 원본 보쿠노 롬에 이 xdelta를 적용한 결과가 검수 후보와 일치하는지 SHA-256으로 확인했습니다.

## 남은 검수

일반 대사 추가 스크롤 후보 57개 문안·창 변형과 특수 UI 후보 432개 변형 등의 검토가 남아 있습니다. 창 상속·동적 이름·탐색 한계가 있는 조건도 전체 검증으로 처리하지 않았습니다. 타프탄 산 이야기는 전체 횟수가 개선됐지만 일부 대기 구간의 초과가 남아 있습니다. **전체 무결함 또는 전수 수리 완료 판정은 아닙니다.**
