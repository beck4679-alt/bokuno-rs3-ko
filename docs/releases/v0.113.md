# v0.113 — 디스코드 검수 제보 수리

v0.112까지의 변경을 포함한 누적 한국어 패치입니다.

## 수정 내용

디스코드 검수 채널에 올라온 화면 캡처 다섯 장의 원인을 찾아 고쳤습니다.

- **전투 훔치기 문구**: 아이템을 훔칠 때 「상처약 / 보랄명대 !」처럼 뜨던 괴문자(번역되지 않은 원문)를 「[아이템]을 / 훔쳤다!」, 「[아이템]을 / 훔쳤지만 / 더 가질 수 없다!」, 「아무것도 가진 게 없다!」로 고쳤습니다. 을/를은 아이템 이름에 맞춰 골라집니다.
- **상태창 내성**: 「퀴쫓·둥C」처럼 깨지던 특수 내성 이름을 「물·던지기·음파·응시·지면」으로 번역했습니다.
- **술집 수행 NPC**: 「패라修양보옷브」처럼 깨지던 수행 권유 대사 31줄을 번역했습니다(「또 수행을 해 / 보지 않겠어요?」 등).
- **트레이드 금액**: 1만 이상 금액의 끝 네 자리가 엉뚱한 글자로 찍히던 문제(「105만짰뭍짰늪오람」)를 고쳤습니다. v0.85부터 트레이드 화면 전체에 있던 결함입니다.
- **트레이드 경매 회사 이름**: 원작의 기울임 연출이 한글 획을 끊어 「사라컴퍼니」가 「샤라콤퍼니」처럼 보이던 것을, 글자 기울임만 꺼서 곧게 표시합니다(밑줄은 원작 그대로).
- **츠바이크 토너먼트 순번 선택**: 그림으로 된 표지 「先鋒·次鋒·中堅·副将·大将·セコンド」를 「선봉·차봉·중견·부장·대장·세컨드」로 바꿨습니다.

## 확인한 범위

- 전체 필수 빌드 검사를 통과했습니다. 본문 24,911행·사전 767칸 되읽기 일치, 이벤트 흐름 919개(실제 비교 802개)에서 원문 대비 차이·잘못된 복귀 0건, 한국어 글 안에서 이벤트가 끝나 대사가 끊기는 자리 0곳.
- 실제 코어 화면: 전투 훔치기 문구 세 가지(받침 있는 이름·없는 이름 모두), 상태창 내성 다섯 칸, 수행 NPC 대사 두 묶음, 토너먼트 순번 표지를 검수 후보에서 실제 에뮬레이터 코어로 확인했습니다(표시 루틴을 직접 실행한 확인이며 실제 게임 진행으로 간 화면은 아닙니다). 경매 화면 회사 이름은 그리기 코드를 실행해 재구성한 그림으로 확인했습니다.
- 트레이드 금액: 105만6864·1만·1234억5678만9012 를 금액 출력 코드로 찍어 숫자 글자가 원작과 같은 칸으로 나오는 것을 확인했습니다.
- v0.112 대비 자리를 옮긴 기존 한국어 글은 22곳뿐이라 전체 대사 재추출은 하지 않았습니다(이벤트 끝 주소 걸림은 빌드 단계에서 막고, 이벤트 흐름 검사가 919개를 원문과 대조합니다).
- 원본 보쿠노 롬에 이 xdelta 를 적용한 결과가 검수 후보와 일치하는지 SHA-256 으로 확인했습니다. 글자 배정은 v0.112 와 같아 기존 세이브를 그대로 쓸 수 있습니다.

## 남은 검수

일부 조연 대사의 「あんた」와 대명사 높임, 사라 선택지 한 곳의 말투, 7×1 영지 경영 창, 새 글꼴의 상태창·장비 메뉴 전체 표시, 트레이드 화면의 자연 진입 후 전체 배치는 확인하지 못했습니다. **전체 무결함 판정은 아닙니다.**
