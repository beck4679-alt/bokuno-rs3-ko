# 알려진 문제와 검수 범위

[메인으로](../README.md) · [설치·오류 해결](INSTALL.md)

## 아직 확인이 필요한 부분

- 작명 화면의 가나 자판은 한글 입력을 지원하지 않습니다(임의 음절이 뜹니다).
- 성장 문구 「업!」 앞 빈칸은 라벨에 따라 1칸 또는 2칸입니다(전부 같은 폭으로 맞추지는 못했습니다).
- 전투의 아이템 목록과 전투 결과 창은 전수 확인하지 못했습니다. 전투의 아이템 획득·기술 습득 메시지는 표시 루틴을 직접 실행해 확인했고, 실제 전투 흐름에서 뜨는 화면은 확인하지 못했습니다. 메뉴·상태창·캐릭터 생성창의 한글은 16px 간격 그대로입니다.
- 가변폭(글자마다 다른 폭)은 대사 창에만 적용됩니다. 메뉴·전투 글자는 새 글꼴 모양으로 나오지만 간격은 예전과 같습니다. 새 글꼴의 메뉴 표시는 주인공 선택·이름 확인 화면만 실제 코어로 확인했고, 상태창·장비 메뉴는 확인하지 못했습니다.
- 군단전 메시지는 시작 장면의 이름(「고블린 프린스」 등)으로 표시를 확인했습니다. 실제 전투에서 더 긴 이름이 들어가는 줄은 확인하지 못했고, 시작 장면 밖 메시지는 원래 전투 흐름이 아니라 같은 표시 루틴에서 메시지 번호만 바꿔 확인했습니다. 군단전 메시지의 한글은 원작 표시 방식대로 글자 사이가 넓게 찍힙니다. 이름 뒤 조사는 시작 장면 이름(「율리안」)으로 화면을 확인했고, 받침 없는 이름 쪽은 코드 시험으로만 확인했습니다.
- 전투 고정 메시지 63개 가운데 실제 전투 흐름에서 직접 확인한 것은 크진시 보스 대사 한 건이고, 나머지 62개는 같은 전투 표시 루틴에서 메시지 번호만 바꿔 끝까지 표시되는지 확인했습니다.
- 대사 배치 검사는 검사기가 닿는 대화 경로만 봅니다. 닿지 못한 경로와, 원문과 짝을 짓지 못해 스크롤 수를 비교하지 못한 풍선은 미측정입니다.
- 영지 경영 목록 창(6×6·14×4)에서 항목이 같은 줄에 붙는 곳 3군데, 트레이드(회사 경영) 화면의 자연 진입 후 전체 창 배치(문구의 조사 선택은 표시 루틴을 직접 실행해 확인), 실제 승리→성장 풍선 흐름, 7×1 영지 경영 창, 15×12 상태표의 이름·숫자 폭은 미측정입니다.
- 검수 중인 공개판입니다. 전체 무결함 판정이 아닙니다.

## v0.117 게코족 대화 끊김·디스코드 제보 수리

- v0.111~v0.116 에서 루퍼스의 그레이트아치(조커) 임무를 받은 세이브는 임무 진행 기록이 남지 않았을 수 있습니다. 이번 판에서 루퍼스에게 다시 말을 걸면 바로잡힐 것으로 보이지만 확인하지 못했고, 그 뒤 단계가 실제로 막혔는지도 확인하지 못했습니다.
- 아이템 정보 창의 술법 증폭 계통 표는 원작 표대로 둘째 칸에도 「백호」가 들어 있습니다(원래 로맨싱 사가 3 에서는 「주작」 자리).
- 「미스」와 같은 전투 표시 글꼴에 들어 있는 다른 일본어 그림 글자(タ·ン·ダ)는 어디서 쓰이는지 찾지 못했습니다. 쓰이는 곳이 있으면 일본어로 나옵니다.

## v0.116 동료 가입 깨짐 수리

- 이미 세이브에 들어간 깨진 기록은 자동으로 고쳐지지 않습니다: 깨진 채로 가입한 동료, 2회차로 넘어와 대기 목록에 들어간 깨진 엘렌, 덮여 사라진 동료(대기 동료 54번째)는 그대로입니다. 깨진 동료를 동료로 삼기 전의 세이브가 있으면 그 세이브를 쓰는 것이 가장 확실합니다.
- 이전 판에서 만든 클리어 데이터로 2회차를 시작할 때 이 자동 정리가 적용되는지는 확인하지 못했습니다.
- 술집에서 동료를 내보낼 때 생긴다는 오류 화면은 재현하지 않았습니다(가짜 기록 때문에 대기 동료 수가 하나 많게 세어진 것과 관련 있을 수 있으나 확인하지 못했습니다).
- 세이브 칸을 고른 뒤 나오는 확인 문구가 「저장해도 (빈칸) 하시겠는가?」처럼 어색하게 나옵니다(이번 확인 중 발견, 아직 고치지 않음).

## v0.115 디스코드 제보 수리

- (v0.116 에서 정정) 엘렌 그림·LP 깨짐 제보는 「재현하지 못했다」고 적었지만 한국어 패치 결함이었습니다. v0.116 에서 고쳤습니다.
- 영지 경영 상태창 잔금의 「만」은 화면으로 띄워 확인하지 못했고 대사 추출 결과로만 확인했습니다.

## v0.114 괴문자 전수 수리

- 이번에 고친 자리는 대부분 자동 검사 도구가 닿지 않는 장면이라, 화면은 대사를 여는 명령부터 직접 실행해 확인했고 실제 게임 진행으로 가서 보지는 않았습니다. 동료 선택지 한 곳(「삼지 않는다」)은 그 방법으로도 화면에 띄우지 못했습니다.
- 같은 부류(자동 검사가 닿지 않는 장면)에서 줄 배치 문제를 하나 보았습니다: 사루인 부하 장면에서 「…넘겨받겠다.」 뒤 「그건 너 같은」이 같은 줄에 이어 붙습니다(원문은 다음 줄로 넘어감). 이런 장면의 줄 배치 검사는 아직 하지 못했습니다.

## v0.113 검수 제보 수리

- 이번에 고친 다섯 화면은 표시 루틴을 직접 실행해 확인했고, 실제 게임 진행으로 그 화면까지 가서 보지는 않았습니다. 트레이드 경매 화면은 그림을 코드로 재구성한 것까지만 확인했습니다.
- 경매 화면 회사 이름은 원작의 기울임 연출을 꺼서 곧게 표시합니다(기울인 채로는 한글 획이 끊겨 읽히지 않았습니다).
- 수행 NPC 대사 가운데 수행을 마친 뒤의 대사는 번역이 들어간 것만 확인했고 화면은 보지 못했습니다. 토너먼트의 대진표·팀 이름 화면은 이번에 보지 않았습니다.

## v0.112 줄 배치 재검사

- 전체 대사 추출(3,865개 이벤트 × 주인공 8명)로 풍선 383,839개의 줄 배치를 다시 검사했습니다. 결함 0곳입니다. 검사기가 결함으로 센 1곳(술법 계통 표의 빈 줄)은 원본 롬도 같은 모양임을 실제 코어로 확인한 검사기 오판입니다. 창 크기를 기록으로 확정하지 못한 지크의 누이 대사(2묶음)는 대사 창으로 쓰이는 두 크기(좁은 창·넓은 창) 모두에서 정상입니다.

## v0.111 번역 손질

대사를 이벤트 순서로 원문과 대조하며 한 번 읽고 고쳤습니다. 두 번째 전수 검토는 하지 않았습니다.

- 일부 조연 대사의 「あんた」와 대명사 높임, 사라의 선택지 한 곳(「후훗, 꼴좋네요!」)의 말투는 아직 원문 방침에 맞추지 않았습니다.
- 7×1 영지 경영 창은 이번 손질 대상이 아닙니다.
- v0.110 에서 공개한 추가 스크롤 후보 수치(57개 변형·특수 UI 432개 변형 등)는 이번 판에서 다시 세지 않았습니다. 문안과 줄바꿈이 바뀌어 수치가 달라졌을 수 있습니다.
