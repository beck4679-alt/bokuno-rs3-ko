# 보쿠노 로맨싱 사가 3 한국어 패치

로맨싱 사가 3 개조판 **「ぼくのロマサガ3」(ぼくのProto1.123)** 의 한국어 패치입니다.

> **피드백·버그 제보는 Discord 로**: **https://discord.gg/3qQ3drmwQV** (장면·대사·창 이름과 스크린샷을 함께 올려 주세요)

**[최신 패치 다운로드](https://github.com/beck4679-alt/bokuno-rs3-ko/releases/download/v0.117/bokuno_ko_v0.117.xdelta)** · [설치 가이드](docs/INSTALL.md) · [변경 내역](docs/CHANGELOG.md)

> **v0.117 · 2026.10.06** — 게코족 해방 이벤트가 대화 도중 끝나 진행이 안 되던 결함(v0.111~v0.116)과 디스코드 제보 4건을 고쳤습니다. 현재 검수 진행 중입니다.

## 시작하기

1. **로맨싱 사가 3 일본판 v1.1** 롬을 준비합니다. 헤더 없는 파일을 사용합니다.
2. [원작 보쿠노 패치](https://ux.getuploader.com/romancingsaga312/download/560)의 **`ぼくのProto1.123.ips`** 를 적용합니다.
3. 위에서 받은 **한국어 패치**를 적용합니다.

**일본판 롬 → 보쿠노 IPS → 한국어 xdelta** 순서입니다. 이전 한국어판에 덧씌우지 마세요.

[처음부터 따라 하는 설치 방법](docs/INSTALL.md) · [파일 확인 값](docs/FILES.md)

## 이번 업데이트

- 게코족 해방 이벤트에서 촌장과의 대화가 도중에 끝나 진행이 안 되던 결함을 고쳤습니다. 2회차와는 관계없이 v0.111 부터 생긴 문제입니다. 그 자리에서 막힌 세이브도 촌장에게 다시 말을 걸면 이어집니다.
- 같은 원인으로 끊기던 데스티니 스톤 설명과 루퍼스의 그레이트아치 임무 대사도 고쳤습니다.
- 사막에 숨은 그림자 선택지, 달의 뼈 정보 창, 마그마프로전 설명, 훔치기 실패 때의 「미스」 표시가 깨지거나 일본어로 나오던 것을 고쳤습니다.

v0.116의 수정(동료 가입 깨짐 등)과 그 이전 수정은 그대로 들어 있습니다. [v0.116 변경](docs/releases/v0.116.md)

v0.116까지의 수정을 포함하는 누적 패치입니다. [자세한 수정·검증 범위](docs/releases/v0.117.md)
