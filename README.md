# 보쿠노 로맨싱 사가 3 한국어 패치

로맨싱 사가 3 개조판 **「ぼくのロマサガ3」(ぼくのProto1.123)** 의 한국어 패치입니다.

> **피드백·버그 제보는 Discord 로**: **https://discord.gg/3qQ3drmwQV** (장면·대사·창 이름과 스크린샷을 함께 올려 주세요)

**[최신 패치 다운로드](https://github.com/beck4679-alt/bokuno-rs3-ko/releases/download/v0.118/bokuno_ko_v0.118.xdelta)** · [설치 가이드](docs/INSTALL.md) · [변경 내역](docs/CHANGELOG.md)

> **v0.118 · 2026.10.07** — 모니카 말투를 리마스터처럼 존댓말 기본으로 바로잡았습니다. 현재 검수 진행 중입니다.

## 시작하기

1. **로맨싱 사가 3 일본판 v1.1** 롬을 준비합니다. 헤더 없는 파일을 사용합니다.
2. [원작 보쿠노 패치](https://ux.getuploader.com/romancingsaga312/download/560)의 **`ぼくのProto1.123.ips`** 를 적용합니다.
3. 위에서 받은 **한국어 패치**를 적용합니다.

**일본판 롬 → 보쿠노 IPS → 한국어 xdelta** 순서입니다. 이전 한국어판에 덧씌우지 마세요.

[처음부터 따라 하는 설치 방법](docs/INSTALL.md) · [파일 확인 값](docs/FILES.md)

## 이번 업데이트

- 모니카가 동료·처음 보는 사람·적·오라버니에게, 동료와 함께 있을 때의 혼잣말까지 존댓말(해요체)을 쓰도록 바로잡았습니다. 반말은 카타리나에게 하는 말, 혼자 있는 밤 장면, 동물·아이에게 하는 말, 짧은 감탄에만 남겼습니다.
- 혼자 있는 오프닝 밤 독백이 존댓말로 나오던 곳과, 한 말풍선 안에서 존댓말과 반말이 섞이던 곳을 고쳤습니다.
- 장면마다 리마스터 대본의 모니카 말투와 맞춰 봤습니다.

v0.117의 수정(게코족 대화 끊김 등)과 그 이전 수정은 그대로 들어 있습니다. [v0.117 변경](docs/releases/v0.117.md)

v0.117까지의 수정을 포함하는 누적 패치입니다. [자세한 수정·검증 범위](docs/releases/v0.118.md)
