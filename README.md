# 보쿠노 로맨싱 사가 3 한국어 패치

로맨싱 사가 3 개조판 **「ぼくのロマサガ3」(ぼくのProto1.123)** 의 한국어 패치입니다.

**[최신 패치 다운로드](https://github.com/beck4679-alt/bokuno-rs3-ko/releases/download/v0.111/bokuno_ko_v0.111.xdelta)** · [설치 가이드](docs/INSTALL.md) · [변경 내역](docs/CHANGELOG.md)

> **v0.111 · 2026.09.26** — 대사 글꼴을 가변폭 갈무리로 바꾸고 번역을 전면 손질했습니다. 현재 검수 진행 중입니다.

## 시작하기

1. **로맨싱 사가 3 일본판 v1.1** 롬을 준비합니다. 헤더 없는 파일을 사용합니다.
2. [원작 보쿠노 패치](https://ux.getuploader.com/romancingsaga312/download/560)의 **`ぼくのProto1.123.ips`** 를 적용합니다.
3. 위에서 받은 **한국어 패치**를 적용합니다.

**일본판 롬 → 보쿠노 IPS → 한국어 xdelta** 순서입니다. 이전 한국어판에 덧씌우지 마세요.

[처음부터 따라 하는 설치 방법](docs/INSTALL.md) · [파일 확인 값](docs/FILES.md)

## 이번 업데이트

- **새 글꼴:** 대사를 갈무리11 좁은체로, 글자마다 폭이 다른 가변폭으로 그립니다. 띄어쓰기가 좁아졌습니다.
- **번역 전면 손질:** 대사를 일본어 원문과 다시 대조해 어색한 번역·오역·빠진 말을 고쳤습니다(약 3,300행). 원문과 같은 곳에서 줄이 바뀌도록 줄바꿈도 함께 맞췄습니다.
- **주인공 말투:** 1인칭·2인칭·어미를 원문 말투에 맞췄습니다(카타리나·모니카의 「나/저」, 원문 「あんた」는 「너」, 권유·추측 문장의 반말·해요체 등).
- 엔딩 능력치 화면의 HP 표시와 「월술L」 줄을 고쳤습니다.

v0.110까지의 수정을 포함하는 누적 패치입니다. [자세한 수정·검증 범위](docs/releases/v0.111.md)
